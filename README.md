# Pulse2MQTT Home Assistant App

Home Assistant packaging for
[SnisLab/pulse2mqtt](https://github.com/SnisLab/pulse2mqtt).

This repository contains no application source. Its image adds the Home
Assistant runtime integration around the released
`ghcr.io/snislab/pulse2mqtt:<version>` image.

Users install this app through the central
[SnisLab Home Assistant Apps](https://github.com/SnisLab/home-assistant-apps)
repository. See `DOCS.md` for configuration details.
